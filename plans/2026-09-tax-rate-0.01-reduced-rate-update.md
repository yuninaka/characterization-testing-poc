# ゴールデンマスター更新: 時限軽減税率0.01の追加

## 変更理由

2027年4月1日から2029年3月31日までの2年間、軽減税率対象の飲食料品について
消費税率が1%（国税0.78%・地方0.22%）に時限的に引き下げられることを想定し、
新税率0.01を検証対象に追加する。既存の軽減税率(0.08)・標準税率(0.10)の
記録は、対象外の取引・期間外の参照用にそのまま残す。

`calculate_price`は`tax_rate`を呼び出し側がそのまま渡す設計であり、
「軽減税率対象品目かどうか」をコード自身が判定する作りにはなっていない。
そのため今回の変更は、軽減税率対象品目の呼び出し側が`tax_rate=0.08`の
代わりに`tax_rate=0.01`を渡すようになる、という形でモデル化した。
`calculate_price`自体のロジックは変更していない。

これはREADME.md「意図した変更時のゴールデンマスター更新フロー」を実際に
一度動かした記録である。

## 影響範囲

`tax_rate`に依存する全ケースのうち、**新税率0.01のケースのみ**。既存の
0.08・0.10のケース(1032件)は対象外。

## 実行コマンド

```bash
uv run python -m scripts.generate_golden_master --tax-rate 0.01
```

## 検証結果

- 変更前: 1032件 → 変更後: 1548件(516件追加、全て`tax_rate=0.01`)
- 既存の0.08/0.10ケース(1032件)は1件も値が変化していないことを
  Pythonスクリプトで突合確認済み(`removed=0`)
- `uv run pytest tests/ -q` → `1548 passed`
- `./scripts/ci_check.sh` → exit code 0(pytest/ruff/mypy/vulture すべて通過)

## 訂正の経緯

当初、税率変更の例として標準税率10%→9%という架空の`tax_rate=0.09`を
用いたが、これは実際の2027年度税制改正の内容（軽減税率対象品目のみを
1%へ時限引き下げ、標準税率は変更なし）と一致しない誤りだった。
実装・コミット前に指摘を受けて`0.01`に修正し、このリポジトリの
`main`には`0.09`版は一度も反映していない。
